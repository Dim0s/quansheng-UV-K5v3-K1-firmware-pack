прошивка не для новичков, ставится только из проприетарного прошивальщика RadioManager и требует соединение по сети
для прошивки рации нужно логиниться по мылу, потребуется ВПН (из за уродов из РКН которые заблочили CDN серваки cloudflire)
_________________________________________________________________________________________
по умолчанию доступна бесплатная версия 4*
из особенностей:
1. FM → AM → AMB → DSB → CW → WFM → BYP
2. Автоматический маяк (CW CALL CQ)
-----------------------------------------------------------------------------------------
ещё есть платные версии 4*PRO и 5*PRO по годовой подписке за 12 евро в которых и есть все плюхи
особенности версии 5*PRO:
1. Канальный спектр
2. Анализатор сигналов
3. 3 VFO
4. SMS ASK
5. Возможность назначать различные клавиши через радиоменеджер
6. Тонкая регулировка практически всего в радиостанции
7. телеграфный режим (CW)
8. Автоматический маяк (CW CALL CQ)
9. поддержка модуля SI4732
10. всевозможное управление рацией через BASIC в RadioManager
11. поддержка голосовых фаилов TTS, даже на русском
12. мультизагрузка профилей, сборка кастомной прошивки и сохранение в один из слотов прессетов, при старте рации можно выбрать любой
13. голосовой попугай, запись и ретрансляция голоса (нужна модификация рации, смотреть фото)
14. репитеры FSK, APRS, голосовой
15. APRS
16. BBS терминал
17. генератор частот
и т.д. все детали смотреть в радио менеджере, залогинившись появятся все модули с описанием

для PRO версии есть кухня самосборки прошивки (автобилд только с нужными модулями которые галочками выберет сам пользователь в прошивальщике)
в папке screenshot есть демонстрация 3 VFO и функций самосборки прошивки
