прошивка разделена на два издания:

издание Fusion включает в себя дополнительный набор функций:
1 - RescueOps - это трансформация рации в детскую зиготу, блокируется вообще всё и даже вход в меню, для запуска назначить кнопку активации в меню в пункте SetKey,
    по умолчанию стоит кнопка MENU, вырубаем рацию и зажимаем PTT + MENU и включаем рацию, готово, для разблокировки повторить процедуру.
2 - установка специальных приложений в формате .app через UV Studio на внешнюю флешку 25Q16 (заходить в окно загруженных приложений на F + 7)

издание Service включает в себя дополнительный набор функций:
1 - AirCopy - полное копирование параметров между рациями, запускать зажав PTT + FN2 и включить рацию
2 - Beam - передача выбранной конфигурации VFO или канала памяти между совместимыми радиостанциями, назначается в меню кнопок
3 - Broadcast FM - приёмник FM
4 - служит для бекапа внешней флешки и полного восстановления стоковой прошивки через UV Studio
_________________________________________________________________________________________
из особенностей:
1. нуу это основа основ, стабильная база из которой делают многие другие прошивки, рекомендую для первого знакомста с прошивками
2. FM AM USB
3. много настроек в меню рации
4. возможность отображать 1 VFO или 2 VFO
5. блокировка всех клавиш и PTT (выбор в меню SetLck)
6. спектроанализатор простой, удобный, средней скорости, без бендов
7. выбор из 12ти разных шрифтов, в главном меню параметр SetFnt под номером 74
8. загрузка своей картинки для вступительного логотипа или заставки через UV Studio
9. подробный журнал RX, TX, мощности передачи, и тд, можно экспортировать данные через UV Studio (работает только если назначен на клавишу в меню)
10. мультизагрузка прошивок которая позволяет закинуть на рацию до 5ти разных прошивок и переключаться между ними через меню рации
    переключание между прошивками запускает локальную перепрошивку, пока этот процесс идёт, рацию не выключать!
    прошивки должны поддерживать эту мультизагрузку, рандомные абы какие прошивки не подойдут (возможно прошьются из меню рации, но только 1 раз и мультименю пропадёт)
    дополнительные прошивки заливать через онлайн прошивальщик UV Studio, офлайн версия этой программы есть в папке прошивальщиков
    основной прошивкой может быть любая из поддерживающих мультизагрузку, не обязательно заливать F4HWN Fusion первой
    в этой системе нет главной прошивки которая обеспечивает весь процесс мультизагрузки, каждая прошивка имеющая мультизагрузку самодостаточна
    список прошивок поддерживающих мультизагрузку смотреть на главной странице репозитория, промотав страницу в самый низ
    вход в меню мультизагрузки: зажать MENU и включить рацию
11. загрузка специальных опциональных приложений в формате .app (что увеличивает число особенностей кратно)
    список приложений смотреть ниже, заливать через онлайн прошивальщик UV Studio, офлайн версия этой программы есть в папке прошивальщиков
    заходить в окно загруженных приложений на F + 7 (выключая, рация запоминает открытое приложение, при следующем включении приложение само запустится, для отмены автозапуска нажать EXIT + вкл рацию)

подробней о логике работы мультизагрузки читайте в разделе репозитория: /прочая информация и фото/разная информация.txt
