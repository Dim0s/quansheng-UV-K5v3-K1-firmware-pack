начиная с версии 5.7.0 в прошивку добавлен подробный журнал, логируется всё и даже частоты TX и мощность.
\_ в дискусии кинул предложение автору прошивки добавить возможность отключения логов, что будет полезней и для флешки, посмотрим что будет дальше.
    \_ начиная с версии 5.8.0 журнал полностью отключен, если ему не назначена ни одна клавиша в меню.

из особенностей:
1. нуу это основа основ, стабильная база из которой делают многие другие прошивки, рекомендую для первого знакомста с прошивками
2. игра арканоид F + 7 (наличие зависит от издания)
3. спектроанализатор простой, удобный, средней скорости, без бендов
4. возможность отображать только 1 VFO
5. FM AM USB
6. много настроек в меню рации
7. загрузка своей картинки для вступительного логотипа или заставки
8. начиная с версии 5.7.0 - подробный журнал RX, TX, мощности передачи, и тд (работает только если назначен на клавишу в меню)
9. начиная с версии 5.8.0 - маяк beacon морзянкой (назначается на клавишу через меню) (в версии 6.0.0+ стал опциональным приложением для издания Labs)
10. начиная с версии 5.8.0 - инструмент для охоты на лис (назначается на клавишу через меню) (в версии 6.0.0+ стал опциональным приложением для издания Labs)
11. начиная с версии 6.0.0 - реализована мультизагрузка прошивок от Armel
    мультизагрузка позволяет закинуть на рацию до 5ти разных прошивок и переключаться между ними через меню рации
    переключание между прошивками запускает локальную перепрошивку, пока этот процесс идёт, рацию не выключать!
    прошивки должны поддерживать эту мультизагрузку, рандомные абы какие прошивки не подойдут (возможно прошьются из меню рации, но только 1 раз и мультименю пропадёт)
    дополнительные прошивки заливать через онлайн прошивальщик "UV Studio v1.6" от Armel, офлайн версия этой студии есть в папке прошивальщиков
    вход в меню мультизагрузки: зажать MENU и включить рацию
    основной прошивкой может быть любая из поддерживающих мультизагрузку, не обязательно заливать F4HWN Fusion первой
    в этой системе нет главной прошивки которая обеспечивает весь процесс мультизагрузки, каждая прошивка имеющая мультизагрузку самодостаточна
    список прошивок поддерживающих мультизагрузку смотреть на главной странице репозитория, промотав страницу в самый низ
12. начиная с версии 6.0.0 - поддерживает загрузку специальных опциональных приложений в формате .app но только на прошивку издания Labs
    список приложений смотреть ниже, заливать через онлайн прошивальщик "UV Studio v1.6" от Armel, офлайн версия этой студии есть в папке прошивальщиков
    заходить в окно загруженных приложений на F + 7
_________________________________________________________________________________________
начиная с версии 6.0.0 была реализована мультизагрузка, из за чего выпуск прошивки разделился на несколько изданий:

 - издание Fusion самая лёгкая версия с вырезанными некоторыми функциями, которые перенесены в другие издания

 - издание FieldOps включает в себя набор функций:
   * RescueOps
   * Fox Hunt - охота на лис, для поиска сигнала;
   * Beacon - передатчик азбуки Морзе

 - издание Transfer включает в себя набор функций:
   * AirCopy - копирование параметров между рациями
   * Beam - беспроводная передача каналов между совместимыми радиостанциями;

 - издание Labs включает в себя набор функций:
   * RescueOps
   * AirCopy - копирование параметров между рациями
   * поддержка установки любых специальных приложений в формате .app через UV Studio v1.6+ на внешнюю флешку 25Q16 (заходить в окно загруженных приложений на F + 7)

   список приложений добавленных с релизом версии 6.0.0:
   * Broadcast FM
   * Fox Hunt - охота на лис, для поиска сигнала;
   * Beacon - передатчик азбуки Морзе
   * Beam - беспроводная передача каналов между совместимыми радиостанциями
   * Breakout - игра арканоид
   * Tetris - игра тетрис
   * Cube3D - вращающийся в реальном времени 3D-куб
   * Plasma - эффект полноэкранной демосцены

   список приложений добавленных с релизом версии 6.1.0:
   * APRS RX - принимает кадры Bell 202 AFSK 1200 AX.25 UI, декодирует распространенные форматы позиционирования и Mic-E, отображает символы APRS и RSSI, а также ведет историю из пяти кадров
   * APRS TX - редактирует и передает APRS-маяки с указанием позывного, SSID, пути, символа и местоположения
   * SSTV - принимает 14 режимов SSTV и может передавать логотип загрузки радиостанции, включая режимы Robot, Martin, Scottie и PD, используемые на мероприятиях ARISS
   * EPIRB 406 - принимает и декодирует сообщения аварийных маяков первого поколения на частоте 406 МГц, включая идентификатор маяка, страну, протокол, местоположение и статус BCH
   * SysInfo - отображает подробную диагностику микропрограммного обеспечения, памяти, внешней флэш-памяти, мультизагрузки и времени выполнения
   * Spectrum3D - отображает быстро прокручивающийся 3D-спектральный водопад
   * Minesweeper - игра Сапер
   * Snake - игра Змейка
   * Space Impact - аркадная игра с боковой прокруткой
   * Rapid Roll - аркадная платформенная игра
   * CWDecode - декодер морзянки

   приложения не совместимы между разными версиями прошивок, если ставите через офлайн версию UV Studio v1.6 используйте только те приложения что идут в одной папке с прошивкой,
   в онлайн версии UV Studio v1.6 выберите версию вашей прошивки и все правильные приложения подгрузятся по сети
