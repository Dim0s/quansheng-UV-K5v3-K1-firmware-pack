2. НАЗНАЧЕНИЕ КЛАВИШ 
лицевая сторона
Долгое "1" - выбор диапазона (только в режиме VFO, в канальном режиме только просмотр, выбрать невозможно)
Долгое "2" - переключение VFO/VFO PRO
Долгое "3" - переключение VFO/CHANNEL
Короткое * (звездочка) - меню LOOT
Короткое 0 (ноль) - открыть\закрыть меню параметров текущего режима приема
Длинное 0 (ноль) - быстрая смена модуляции в режимах VFO
F(#) - меню создания и сохранения каналов, VFO И т.п.
EXIT - быстрое переключение между VFO (в версии s0va-by-fagci-20250505_1733 не актуально)
Короткое "М" - меню выбора приложений
Долгое "М" - основное меню настроек радиостанции
левая боковая сторона:
РТТ - передача (в режиме канала/VFO), остановка сканирования с переносом частоты в VFO (в режимах спектроскопа или сканеров)
FN1 - добавить (убрать) канал/частоту в ЧС (черный список, blacklist)
FN2 - добавить (убрать) канал/частоту в БС (белый список, white list)

7. Приложение LOOT 
Является, по сути, журналом в который автоматически сохраняются все активные частоты в процессе работы модулей сканирования, спектроанализатора,  захвата частоты.
Предназначено для оперирования данными частотами.
Вызывается по краткому нажатию клавиши "звездочка" во всех приложениях. Выход - "exit"
Клавиши управления:
 вверх-вниз - навигация по списку, 
FN1 - добавить (убрать) канал/частоту в ЧС (черный список, blacklist) добавляет значок "минус" слева от значения частоты
FN2 - добавить (убрать) канал/частоту в БС (белый список, white list) добавляет значок "плюс" слева от значения частоты 
Короткое "5" (exit)- отображение ранее сохраненных каналов
длинное "5" - сохранение сразу частот помеченных "+" в свободные каналы
"1", "2" - сортировка по очередности добавления и количеству активности 
длинное "0" - очистка журнала
Сканирование субтона - в луте нажать "7 "
Восклицательный знак в статусной строке (верх экрана) сигнализирует о достижении лимита (переполнения) списка, в таком случае, его следует обработать и очистить.
Перемещаемся по списку, прослушиваем, помечая частоты  для сохранения в каналы, сохраняем (длинное 5), после этого очищаем список (длинное 0)
Радуемся ;).


8. "Channels" 
Работа с сохраненными каналами и диапазонами
вызывается приложение из меню по короткой "М"
"0" переключение между каналами и бэндами 
"*" - переключение типов операций с каналами и бэндами (инфо, вкл-выкл ТХ, ("1" меняет состояние ), просмотр списков сканирования, добавление в списки сканирования, удаление)

После добавления каналов в списки сканирования, возможно отображение по спискам. 
Для этого жмем звездочку до "CH SL SEL" (в статусной строке) и номер списка 1-8 коротко для отображения нужного списка, списки под литерами A-H (9-16) вызываются длинным нажатием 1-8.

Добавление каналов в списки сканирования:
жмем звездочку несколько раз до отображения в статусной строке 
 режима "CH SL", выбираем канал (кн вверх-вниз) , добавляе в нужный список нажатием 1-8 (короткое для добавления в списки 1-8, длинное для добавления в 9-16), принадлежность канала к какому-либо списку отображается точками справа в строке канала (жирная точка - канал добавлен в соответствующий список, обычная точка - нет) .
Списки можно использовать в канальном сканере.

"CH TX" - единичкой переключается передача
