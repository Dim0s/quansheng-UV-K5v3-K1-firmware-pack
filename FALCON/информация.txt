из особенностей:
1. поддерживает 4096 каналов
2. спектроанализатор быстрый, фильтрующий шумы, умеет сканировать по диапазону частот, каналам, листам или сразу несколько бендов (настройки спектра вызывать на долгое удержание MENU)
   листы и бенды можно создавать и редактировать прям на рации (заходим в скан по бендам на F + 8, потом жмём MENU чтоб попасть в окно выбора бендов, потом долго зажимаем MENU чтоб появилось окно создания и редактирования бенда)
   на 4 выбрать несколько бендов и на EXIT запустить скан всех выбранных
3. возможность отображать 1 VFO или 2 VFO
4. FM AM USB
5. несколько уникальных звуков Rogger
6. маяк, пищит выбранным звуком Rogger через определённое время (пункт в меню - AUROG)
7. много настроек в меню рации
8. блокировка клавиш и PTT
9. возможность назначить на боковые кнопки второе PTT для неактивного VFO (отпадает надобность переключать A/B для передачи)
10. поддерживает мультизагрузку прошивок от Armel
    мультизагрузка позволяет закинуть на рацию до 5ти разных прошивок и переключаться между ними через меню рации
    переключание между прошивками запускает локальную перепрошивку, пока этот процесс идёт, рацию не выключать!
    прошивки должны поддерживать эту мультизагрузку, рандомные абы какие прошивки не подойдут (возможно прошьются из меню рации, но только 1 раз и мультименю пропадёт)
    дополнительные прошивки заливать через онлайн прошивальщик "UV Studio v1.6+" от Armel, офлайн версия этой студии есть в папке прошивальщиков
    вход в меню мультизагрузки: зажать MENU и включить рацию
    основной прошивкой может быть любая из поддерживающих мультизагрузку, не обязательно заливать F4HWN Fusion первой
    в этой системе нет главной прошивки которая обеспечивает весь процесс мультизагрузки, каждая прошивка имеющая мультизагрузку самодостаточна
    список прошивок поддерживающих мультизагрузку смотреть на главной странице репозитория, промотав страницу в самый низ
11. поддерживает загрузку специальных опциональных приложений в формате .app (что увеличивает число особенностей кратно)
    список приложений смотреть ниже, заливать через онлайн прошивальщик "UV Studio v2.0+" от Armel, офлайн версия этой студии есть в папке прошивальщиков
    заходить в окно загруженных приложений на F + 5

подробней о логике работы мультизагрузки читайте в разделе репозитория: /прочая информация и фото/разная информация.txt

управление в приложении FMessage:

отправляет за раз до 48 символов.

Все радиостанции должны работать на одной частоте (активный VFO).

 - Установите приложения FMessage и FMessageOption с помощью UV Studio.
 - В приложении FMessageOption установите ваш 2-символьный позывной, если хотите звук приема, и звук вызова (позволяет узнать, кто вызывает).
 - Откройте приложение FMessage: позывные радиостанций, на которых открыто это приложение, отображаются под надписью "Здесь".
 - Нажмите кнопку PTT для вызова: звук вызова воспроизводится на радиостанциях, на которых приложение не открыто, чтобы их пользователи знали, что их вызвали, и могли открыть приложение.
 - Введите сообщение с помощью клавиш 0-9: однократно нажимайте для ввода букв, удерживайте для ввода цифр, 0 для пробела, 1 для знаков пунктуации (., ?, !, -), * для удаления, удерживайте * для очистки всего сообщения, < > для перемещения курсора.
 - Нажмите F для отправки сообщения всем. Рядом с каждым позывным радиостанции, получившей сообщение, появляется значок "+". Нажмите F еще раз (RESEND) для повторной отправки того же сообщения.
 - При получении нового сообщения раздается звуковой сигнал, и зеленый светодиод мигает, пока сообщение не будет прочитано. На главном экране отображается "1 NEW".
 - Нажатие клавиши M открывает "ВХОДЯЩИЕ СООБЩЕНИЯ" (8 сообщений, * = непрочитанные). Нажатие клавиши M открывает выбранное сообщение; в сообщении нажатие M возвращает на главный экран для ответа.
 - Нажатия клавиш F и PTT игнорируются с кратким звуковым сигналом, если частота занята.
 - Сообщения теряются при выходе из приложения. При выходе приложение запрашивает подтверждение, если какие-либо сообщения были сохранены.
